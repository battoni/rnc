## How to read this documentation

Use the **User / Developer** switch at the top-right to choose the depth:

- **User** — step-by-step, plain language, no technical detail.
- **Developer** — the same pages, plus schemas, endpoints, diagrams and the reasoning
  behind each decision.

::: tip
The same pages serve both audiences — flip the switch any time. Nothing is hidden from
search, so you can always find a term regardless of the mode you're in.
:::
