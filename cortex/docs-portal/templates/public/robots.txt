# The documentation portal for {{TITLE}}.
#
# The pages are staff-gated by `middleware.ts`, and this file is served ANYWAY: the
# middleware's matcher deliberately excludes `.txt`, `.xml`, `.json` and assets, so a
# crawler reads this even though it can read nothing else. That is why the file is worth
# having here and not in codelumen, whose gate matches `/:path*` and answers a request
# for /robots.txt with a redirect to GitHub.
#
# THE GATE IS DESIGNED TO BE DELETED. `.env.example` says so in as many words: a project
# whose docs are public removes `middleware.ts`, `middleware/` and that file. The moment
# it does, this portal — endpoint tables, the schema book, the view map, a client's whole
# API surface — is on the open internet, and THIS file, the `X-Robots-Tag` header in
# `vercel.json` and the robots meta in `.vitepress/config.mts` are the only things still
# saying no. This file asks a crawler not to fetch; the header and the meta tell one that
# fetched anyway not to keep the page.
#
# So the safe default lives here, and a portal that genuinely wants to be found removes
# these three deliberately. Getting it the other way round is not recoverable: an indexed
# schema stays in someone's cache long after the header is corrected.

# Every crawler, every path.
User-agent: *
Content-Signal: search=no, ai-input=no, ai-train=no
Disallow: /

# are USER-TRIGGERED fetches, which their operators document as not bound by robots.txt

# is the only statement that reaches them at all.
