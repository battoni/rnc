# Generate RULES.md

The prompt for generating a component, view or module `RULES.md` in `app.rnc/src/` lives in one
place: **`.claude/commands/battoni-generate-component-rules.md`** (run it as
`/battoni-generate-component-rules`; Cursor reads the same body from
`.cursor/rules/battoni-generate-component-rules.mdc`, regenerated by `make sync-mirror`). For an
api.rnc unit, the prompt is `.claude/commands/battoni-generate-api-rules.md`.

It writes the whole unit: the `RULES.md` with its `version / origin / based-on` frontmatter, the
sibling `CHANGELOG.md` (`cortex/sync/SCHEMA.md`), and the sections a unit documents — including
`## Test IDs` and `## Known Gaps`. The global rules it must not repeat are `.claude/rules/celer-*`
and `.claude/rules/shared-conventions.md`.

Agents receive the full `RULES.md` chain on Edit/Write through the pre-edit hook
(`cortex/hooks/inject-rules-context.py`); closer files take priority.

**Retired:** the full prompt that used to live here. It was a second copy, and it drifted — no
frontmatter, no CHANGELOG, no Test IDs or Known Gaps, and a pointer to `cortex/vue-rules/`, a
folder deleted long ago — while the command was kept current. One copy cannot disagree with
itself.
