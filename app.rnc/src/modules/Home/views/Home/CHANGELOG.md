# Changelog — HomeView

All notable changes to this unit are documented here. Versioned with SemVer.
This file is the canonical source for the unit's version (RULES.md frontmatter mirrors it).

## 1.3.0 — 2026-11-14

### Changed

- The firm-less operator stays here while a view-as is on (rnc-4 F4d, R26).

## 1.2.0 — 2026-11-14

### Changed

- The firm-less platform operator (rnc-4 R24) is sent on to the platform console with `router.replace`, rendering nothing; the redirect also asks the console's key, so a refused console never loops back here.

## 1.1.0 — 2026-11-07

### Changed

- A partner's login is sent on to `/parceiro` and sees nothing here (rnc-2 F1, A4). The rnc-1 greeting and workspace cards were already here; the RULES' placeholder note is retired.

## 1.0.0 — 2026-05-30
