# app.rnc — the authenticated app of a product built on the rnc bootstrap.
#
# Nothing here is meant to be indexed, quoted, or used as training data. Every screen
# is behind a login, and the product's public surface is vitrum, not this.
#
# THIS FILE IS A REQUEST, NOT A CONTROL. It stops well-behaved crawlers only. The
# instruction that binds is the `X-Robots-Tag: noindex` header in `vercel.json` — see
# DEPLOY.md — and the protection is the login. Keep all three; they fail differently.
#
# The failure this prevents cannot be undone later: a staging deploy indexed with
# production-shaped data stays in someone's cache after the header is fixed.

# Every crawler, every path.
User-agent: *
Content-Signal: search=no, ai-input=no, ai-train=no
Disallow: /

# Listed individually as well: several AI operators honour only their own token and
# treat the wildcard above as not addressed to them.
#
# `Content-Signal` is repeated in this group on purpose, and it is not redundant with
# `Disallow`. Three of the tokens below — Claude-User, ChatGPT-User, Perplexity-User —
# are USER-TRIGGERED fetches, which their operators document as not bound by robots.txt
# exclusion: somebody pasted a link and the agent goes to read it. For those, this line
# is the only statement that reaches them at all.
