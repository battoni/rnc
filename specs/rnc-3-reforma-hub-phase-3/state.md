## Pitfalls
- (F5) The app's ClickGuard (`src/plugins/ClickGuard`) locks a clicked button until its request settles (`data-click-guard="locked"`), and Enter in a form clicks that same button: an e2e that asks twice in a row must wait for the guard, or the second submit is silently dropped.
- (F5) A spec that renders a view using module molecules registers them in `global.components` — Vitest has no auto-import (`MAnswerCard`, `AEmptyState`).
- (F5) `brandTintText.spec` refuses `bg-primary-50` with any `text-primary-<n>` but 950.
- Every rnc-1 and rnc-2 pitfall still holds (`specs/rnc-1-reforma-hub-pilot/state.md`, `specs/rnc-2-reforma-hub-phase-2/state.md` → Pitfalls).
- This worktree runs the gate as `E2E_PORT=5176 make pre-commit`; with the default port Playwright reuses another checkout's server on 5173 (`app.rnc/e2e/RULES.md`). Live checks: API on 8013, SPA on 5176, its own SQLite.
- rnc-2 is built in parallel in `rnc-wt-2` and folds columns into the same `create_*` migrations (`leads`, `referrals`, `firms`, `clients`): expect merge conflicts there; keep both column sets, then `make fresh-seed`.
- `users` is not firm-scoped and the operator has `firm_id` set: there is no cross-firm operator access (Firm `RULES.md`), so every Phase 3 screen works inside Franco's firm.
- The SPA never sent `X-Firm`; F1 adds `X-Brand` only on public calls — never on back-office calls, where the brand is irrelevant.
- (F1) The Bash hook (rtk) rewrites commands and auto mode then refuses them: call tools by absolute path (`/usr/bin/grep`, `/bin/cat`) or through a script, and run the gate from a script.
- (F1) `check-api` runs `pint --test` BEFORE `sanitize` fixes anything: run `vendor/bin/pint` on touched PHP files before the gate, or it stops at the static checks.
- (F1) PHPStan refuses `$x?->y ?? z` (`nullsafe.neverNull`): `??` already tolerates null, write `$x->y ?? z`.
- (F1) In a test, `refresh()` after a request reads under the firm that request left in `CurrentFirm`; another firm's row needs `withoutGlobalScopes()`.
- (F1) A new permission group needs its `rolesAndPermissions.groups.<id>` (and any new `permissions.<label>`) in `app.rnc/src/locales/local/{en,pt-BR}.json`.
- (F1) Phase 3 migrations use the `2026_11_07_3000NN` sequence so their file names never collide with rnc-2's.
- (F2) A Vitest spec that changes the address bar resets it (`history.replaceState({}, '', '/')`) and `sessionStorage` after each test: the brand is read from both, and a leftover `?marca=` re-themes the next spec.
- (F2) In e2e, measure a colour through a canvas (`brands.spec.ts` → `renderedPairs`): `bg-canvas/90` computes to `oklab(…)`, which a regex reads as black. Use `page.emulateMedia({ colorScheme })` before `goto` for the dark scheme; setting `data-theme` by hand left the canvas dark in "light".
- (F3a) An advance names its target (`{to}`); the SPA sends the row's `next_stage`, never computes it.
- (F3b) A live check from the SPA on 5176 needs the API served with `CORS_ALLOWED_ORIGINS=http://localhost:5176 SANCTUM_STATEFUL_DOMAINS=localhost:5176 FRONTEND_URL=http://localhost:5176`; without CORS the SPA never reaches `auth/me` and lands on `/entrar`. Sign in with `qa/login-as/<user>` as a top-level navigation, then set `app.rnc:session-hint` on the 5176 origin.
- (F3b) A Vitest assertion on an `Intl` amount must normalise spaces (`plain()` in the Channel specs): "R$ 1.575,00" carries a non-breaking space and `toContain` with a plain one fails while the message shows identical strings.
- (F3b) A PrimeVue component used for the first time in a template (here `InputNumber`) must be added to `optimizeDeps.include` in `vite.config.ts`, or `src/test/optimizeDeps.spec.ts` fails the gate.
- (F3a) Reinaldo's board has no `monthly_fee_cents`, `share_bp`, `notes` or `defaults` keys at all (AM15, W39): F3b must not read them unguarded.
- (F4) A `Http::`-style word in a module's Markdown trips a code scan that reads every file: `AssistantDriverTest` scans `.php` files only, and a module's RULES.md may say what the scan forbids.
- (F4) A custom cast (`UtcDateTime`) caches the value it was set with: right after `update(['reviewed_at' => now()])` the model still holds the São Paulo instant, so a resource writes `->utc()->toIso8601String()`.
- (F4) An `ApiResponse::error` puts its i18n key under `error`, not `message`: assert `assertJsonPath('error', …)`.
