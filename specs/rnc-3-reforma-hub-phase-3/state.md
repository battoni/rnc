- (F1) PHPStan refuses `$x?->y ?? z` (`nullsafe.neverNull`): `??` already tolerates null, write `$x->y ?? z`.

- (F1) A new permission group needs its `rolesAndPermissions.groups.<id>` (and any new `permissions.<label>`) in `app.rnc/src/locales/local/{en,pt-BR}.json`.
- (F1) Phase 3 migrations use the `2026_11_07_3000NN` sequence so their file names never collide with rnc-2's.
- (F2) A Vitest spec that changes the address bar resets it (`history.replaceState({}, '', '/')`) and `sessionStorage` after each test: the brand is read from both, and a leftover `?marca=` re-themes the next spec.
- (F2) In e2e, measure a colour through a canvas (`brands.spec.ts` → `renderedPairs`): `bg-canvas/90` computes to `oklab(…)`, which a regex reads as black. Use `page.emulateMedia({ colorScheme })` before `goto` for the dark scheme; setting `data-theme` by hand left the canvas dark in "light".
