## Pitfalls
- Node 24 (`.nvmrc`); the shell's nvm default is 20 — run `source ~/.nvm/nvm.sh && nvm use` first.
- Valet is broken in non-interactive shells (`_valet_run` not found): serve the API with `php artisan serve`.
- Pest runs on in-memory SQLite; production will be MySQL 8 — migrations must work on both (AM11).
- A throwaway database for a run: `DB_CONNECTION=sqlite DB_DATABASE=/abs/path.sqlite php artisan …` (shell variables win over `.env`, `serve` included).
- The login throttle (`throttle:login`) answers 429 after a few scripted attempts; `php artisan cache:clear` resets it locally.
- Signed-in e2e specs start at `/painel`; `/` is the public site and has no rail.
- `DatabaseSeeder` runs WITHOUT model events: `BelongsToFirm` does not stamp `firm_id` in a seeder, and `FirmScope` hides every row unless the seeder runs inside `CurrentFirm::runAs` (see `SectorPageSeeder`).
- The router aborts every request in flight on navigation, so an event sent through `API` right before a `push` is lost — tracking uses `navigator.sendBeacon` (`recordEvent.service.ts`).
- The theme paints `.router-link-exact-active` with the rail's glowing bar; a site `RouterLink` that can match the current page sets `exact-active-class`.
- `ALogo`'s own `inline-flex` outvotes a `hidden` passed to it: wrap it in a span to hide it responsively.
- The public shell clips sideways overflow (`overflow-x-clip`), so a too-wide header shows as a cut button, not a scroll — `e2e/site` measures the header CTA against the viewport.
- Vitest has no component auto-import: a view spec registers the module's molecules and PrimeVue's `Button`/`Skeleton` in `global.components`.
- A rtk-filtered `make pre-commit` log drops the suite counts; run the suites directly to count them.
- Laravel's plain `throttle:N,M` keys by address only, so every route using it shares ONE counter: give each limiter a prefix (`throttle:10,1,cnpj-lookup`).
- A Pest dataset value that is a closure is passed as-is to a `Closure` parameter: `fn () => fn () => …` never runs the inner one (it once let a test reach the real BrasilAPI). Put `Http::preventStrayRequests()` in every test file that fakes HTTP.
- The base theme's `label { text-transform: uppercase; font-family: mono }` is unlayered, so a Tailwind utility cannot outvote it — override in `franco.css` (`label:has(.p-checkbox)` does it for checkbox sentences).
- A diagnostic step's tracking event must carry the lead token (`track(type, sector, token)`), never a lead id.
- `APP_TIMEZONE` is America/Sao_Paulo, so Eloquent's `datetime` stores local time: a UTC column needs the `UtcDateTime` cast (Booking), and queries compare formatted UTC strings.
- `fake()->uuid()` is not always v4; `StartDiagnosticRequest` wants `uuid:4` — use `Str::uuid()` in tests.
- The ClickGuard locks a button 350 ms after a click: an e2e that clicks the same button again after a short `fill` waits for `data-click-guard` to drop.
- `APP_LOCALE` is `en`: a Mailable for a visitor sets `->locale('pt_BR')`.
- The auto-mode classifier refuses a broad `pkill`; serve with background tasks and stop them by id.
- A wide child inside `TheLayout`'s flex column widens the page: a sideways-scrolling strip needs `w-0 min-w-full overflow-x-auto` (the board pushed 1440 px out by 83 px without it).
- `brandTintText.spec` refuses `text-primary-<n>` on a `bg-primary-50/100/200` tint: use `text-primary-950`.
- Playwright's `dragTo` drops on the target's centre — on a tall column that can land on a card; give `targetPosition` near the header.
- Vitest runs in English with `en-US` dates (`11/16`); the pt-BR wording is checked live.
- `ApiResponse::paginated` takes `Illuminate\Pagination\LengthAwarePaginator` (the concrete class): a repository typed with the Contracts interface fails larastan.
- PrimeVue `Select` cannot be opened in jsdom: a spec stubs it with a native `<select>` that emits `update:modelValue` (TrailView, PartnersView specs).
- `tsconfig` lib has no `Array.prototype.at` — `vue-tsc` refuses `.at(-1)` even in a spec.
- `motionTokens.spec` refuses a literal `duration-500`: use the `motion-settle`/`motion-calm` utilities; `unifiedClassBinding.spec` refuses `class` beside `:class` on one element (put the static classes in the `:class` array).
- A grid item with `sm:order-last` drops to a new row when a later item spans columns: place each cell with explicit `col-start`/`row-start` (the funnel chart's count fell under its bar at 1440).
- Rail children render only while their group is expanded: a check for a child's link must open the group's route first.
- `scrollIntoView` inside `TheLayout` also scrolls `#app` and the document: the whole layout lifts off the top and leaves a blank screen. Scroll the `.main-scroll` ancestor with `scrollBy` instead (`RepricingView::scrollToDetail`).
- A rtk-filtered `node`/command whose output repeats an earlier one prints `[↑NL same as msg …]`: write the output to a file and read it.
