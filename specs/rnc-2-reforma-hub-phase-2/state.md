## Pitfalls
- Every rnc-1 pitfall still holds (`specs/rnc-1-reforma-hub-pilot/state.md` → Pitfalls); the plan's P1–P10 carry the ones that bite here.
- `facts.md` §5 (NF-e tag paths, CRT codes, `verProc`) is general knowledge, not fetched: the parser reads defensively and the screens call the figures estimates.
- From F1 on, a new route not classified in `tests/Feature/Access/routeClasses.php` fails A2 — classify it in the same phase.
- The operator holds every key but has no `partner_id`: the portal answers it 403 `portal.noPartner`, by design.
- Pest helper functions are global across files: prefix them per file (`access*`, `portal*`, `matrix*`), or two files declaring one name is fatal.
- A Pest test that replays a real cookie must forget the guards AND `app()->forgetInstance('auth.driver')`: otherwise the `sessions` row is written with the previous `actingAs` user's id.
- `CarbonImmutable::setTestNow('2026-11-09 13:00:00')` is São Paulo time (APP_TIMEZONE); a UTC assertion needs `parse('…Z')`.
- SPA specs: `translatedMessage` is set by the axios interceptor, which `renderWithPlugins` does not install — branch refusals on the API's `code` (`PARTNER_ACCESS_ERROR_KEYS`), never on the sentence.
- `npm run sort-locales` sorts only the core `en.json`/`pt-BR.json`; the LOCAL files under `locales/local/` keep append order (as rnc-1 left them).
- A class-cast attribute (`UtcDateTime`) read back on the same model after `update()` is the object that was SET (its zone kept, e.g. `-03:00`), not the stored UTC: format through `->utc()` before writing it anywhere (F2's timeline line hit it).
- `Referral::create([... 'created_at' => …])` in a Pest test drops `created_at` (not fillable) — use `forceCreate`; seeders run unguarded, tests do not.
- A Lead looked up in a Pest test with no `CurrentFirm` set is `null` under `FirmScope`: `Lead::withoutGlobalScopes()->find()`.
- Every new portal route goes in `routes/api.local.php` with `$portal` (`auth`, `permission:portal.access`, `portal`) and in `routeClasses.php` as `portal`; the matrix also checks the middleware structurally.
- The portal's components are `@PortalModule` and Partner imports `MSlaChip`/`SLA_STATE` from it (one-way: Portal reads only the `partners.specialties` strings and must never import `@PartnerModule`, or the barrels cycle).
- A money string from `formatReal` has a NO-BREAK space after `R$`: assert with `/R\$\s12\.000,00/`, never `'R$ 12.000,00'`.
- A new PrimeVue component in a template must be added to `vite.config.ts` → `optimizeDeps.include`, or `src/test/optimizeDeps.spec.ts` fails.
- A Pest dataset value that calls code (an `NfeFixture::nfe()`) is evaluated when the file loads: wrap it in `fn () =>`, or a missing class surfaces as a misleading `DatasetMissing`.
- `UploadedFile` (Symfony) already strips the path from the client's name: a `'../../x.xml'` upload arrives as `x.xml`, so a test of the app's own `basename` cannot go red — assert where the FILE lands instead.
- A request without `actingAs` later in the same test is still signed in as the last `actingAs` user: put the guest's 401 first, or in its own test.
- The Fiscal tests fake the `local` disk (`Storage::fake('local')`); the live check writes real files under `api.rnc/storage/app/private/nfe/` (gitignored).
- `DatabaseSeeder` runs under `WithoutModelEvents`: inside the seed chain `BelongsToFirm`'s `creating` stamp never fires, so a seeder that goes through a module's service needs the service to write `firm_id` itself (F6b's `NfeImporter`).
- Pest's `arch()->not->toUse('Vendor')` ignores a dependency whose class does not autoload: an SDK that is not installed is invisible to it. Prove such a test red with a stub autoloaded for the run (a temporary PSR-4 entry + `composer dump-autoload`, restored after), and pair it with a `composer.lock` check.
- A global Pest helper cannot append to a property set in `beforeEach` (`test()->x[] = …` → "Indirect modification of overloaded property"): keep per-test state in a `static` inside a prefixed helper (`nfeFolderTrack`).
